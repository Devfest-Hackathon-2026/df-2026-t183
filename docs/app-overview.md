# Teach Back（日本語名：AIに教える）アプリ概要

## どんなアプリか

授業や参考書で学んだ内容を、何も知らない設定の AI に自分の言葉で説明する。AI が説明の理由や具体例を聞くので、学習者は「わかったつもり」の箇所に気づき、教材に戻るきっかけを得られる。

## 誰が使うか

高校生・大学生を中心に、授業や試験、資格の勉強を一人で振り返りたい人。PC・タブレット・スマートフォンのブラウザで利用する。

## 使い方

1. ホームから学習を始める。ログインは不要。
2. 教材の文章を貼り付けるか、UTF-8 の TXT またはテキストを含む PDF を1つ選び、読み取った本文を確認する。
3. AI の質問に自分の言葉で答え、納得するまで説明を足す。
4. 自分で終了を選び、説明できた点（まとめと根拠の発言）と次に復習する点を確認する。教材本文・会話・振り返りをサーバーに保存し、12文字の閲覧キーを発行する。
5. 後日は、控えた閲覧キーをホームで入力して1件ずつ開く。キーを知っている人は閲覧・削除でき、紛失すると再発行できない。

## 今回の範囲

- 3段階で作る。第1段階は文字での対話と振り返り、第2段階は保存と閲覧キーによる再閲覧、第3段階は削除。
- 音声入力とAIの質問の読み上げは任意の追加機能とする。学習者が確認・修正した文字だけを対話に使い、AIの質問は文字でも表示する。ISBN、ロードマップ、プロフィールやアカウント別の一覧は後の候補とする。
- 学習 API は Go と Cloud Run、AI は Vertex AI 経由の Gemini、保存先は Firestore。画面は React・TypeScript・Vite を有力案とする。
